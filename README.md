## Things to remember before submitting

- Generate solutions using the latest frontier models available at the time of generation. Outdated models are not allowed.
- Prefer high reasoning effort when generating solutions.
- Include at least two proof-of-solution runs per task, generated by two different frontier models, with their solutions and verification records stored in `proof-of-work/`.
- Ideally, each model-generated solution should earn a final verifier score below 40%.
- Exclude generated dependencies, build output, local databases, and secrets from the submission.
- Once the task is done, use AGENTS.md to verify the task.
