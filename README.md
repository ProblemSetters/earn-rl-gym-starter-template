## Things to remember before submitting

- Generate solutions using the latest qualifying frontier model versions available at the time of generation. Outdated models are not allowed.
- Use medium reasoning effort when generating proof-of-solution runs.
- Include at least two proof-of-solution runs per task, generated by two different qualifying frontier models, with their solutions and verification records stored in `proof-of-work/`.
- Each qualifying model-generated solution should earn a final verifier score below 30% in a single pass. Scores of 30% or higher should be flagged for review.
- Exclude generated dependencies, build output, local databases, and secrets from the submission.
- Once the task is done, use AGENTS.md to verify the task.
